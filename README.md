# Demonstrator 2

Repository for the 3D Label Free Demonstrator 2 setup.

### Motivation:
- Control devices.
  - Sweeping laser source.
  - Camera acquisition.
  - Sample stage.
- Synchronise sweep source with camera acquisition.
- Image data IO.
- Automate B-scan.

### Project structure
```commandline
__root__
├ config (untracked)
├ data (untracked)
├ demonstrator2 (project)
│ ├ dem2_common (sofware package)
│ ├ dem2_components (hardware control package)
│ ├ dem2_devices (hardware package)
│ └ t.b.d.
├ logs (untracked)
├ .gitignore
└ README.md
```
