# dem2_stage.py

Contains the `Dem2Stage` class.

To use:
- Instantiate a `Dem2Stage` object.
- Ensure the stage is connected to the computer and objective is removed.
- Run `connect()`, `initialize()`, and `calibrate()` sequentially.
- After use, disconnect with `disconnect()`.
