# dem2_common Package

Software package.

Includes:
- dem2_bscan_pattern - The pattern of movements for the state, including focus positions.
- dem2_constants - Constant variables for the project.
- dem2_errors - Error classes for the dem2 project.
- dem2_helper - Helper script with function useful project wide.
