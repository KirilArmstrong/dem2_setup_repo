# Packages

The following are the current packages:
- [[dem2_common]](https://github.com/myleneamstutz/3d_label_free_dem_2/blob/dev/dem2_doc_vault/Packages/dem2_common.md) - Software package.
	- I.e. for data handling, IO, and processing.
- [[dem2_components]](https://github.com/myleneamstutz/3d_label_free_dem_2/blob/dev/dem2_doc_vault/Packages/dem2_components.md) - Hardware control package.
	- I.e. for control or managing scripts.
- [[dem2_devices]](https://github.com/myleneamstutz/3d_label_free_dem_2/blob/dev/dem2_doc_vault/Packages/dem2_devices.md) - Base hardware package.
	- I.e. for a script handling the camera hardware.
